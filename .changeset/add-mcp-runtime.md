Add MCP client support for agents and subagents. Register named MCP folders directly on each agent, discover all server tools at runtime, and execute namespaced MCP tools through the durable provider tool loop. Streamable HTTP works across Node.js, browser, Expo, and React Native builds, while stdio is available for Node.js targets. The MCP SDK remains optional and is installed only for projects that configure MCP connections.
